# Hypertrofia Tracker

Aplicación web progresiva para registrar entrenamientos orientados a hipertrofia.

## Versión 3

- Rutinas Upper, Lower, Full body y personalizadas.
- Selector visual de músculos y ejercicios frecuentes.
- Registro de peso, repeticiones, RIR, calentamientos y descansos.
- Programación de rutinas y mesociclos.
- Progresión automática por ejercicio.
- Volumen directo, indirecto y fraccional.
- Check-in de recuperación, hidratación y medidas corporales.
- Respaldo JSON/CSV y sincronización opcional con Supabase.

La aplicación funciona localmente y sin conexión. Consulta `SUPABASE_SETUP.md` para activar la sincronización entre dispositivos.
